Questions and Answers

1. What is the difference between block tags and inline tags?

Block tags start on a new line and usually take the full width. Inline tags stay in the same line as other text.

2. What are margin, border, and padding?

Margin is space outside the border. Border is the line around the box. Padding is space between the content and the border.

3. What units of measurement can you use in CSS?

CSS units include px, %, em, rem, vw, and vh. They help set sizes, spacing, and font sizes.

4. When would you use a figure tag?

I would use a figure tag when I want to group an image with a caption.

What I Learned

Pixels usually stay the same size. Percentages and viewport units change with the size of the browser window. Em and rem depend on font size.
