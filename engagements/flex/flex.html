What I Learned About Flex and CSS

I learned that Flexbox helps arrange items in a row or a column. I learned how to use display flex, flex direction, flex wrap, and gap to organize items and add space between them.

Why Is Website Accessibility Important?

An accessible website makes it easier for everyone to use, including people with disabilities. It should have clear text, descriptions for images, and keyboard navigation so more people can use the website easily.
