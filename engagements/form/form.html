Questions and Answers

1. What is JavaScript? How did it get its name?

JavaScript is a programming language used to make websites interactive. It was first called LiveScript and later renamed JavaScript.

2. What are the two ways you can run JavaScript?

We can run JavaScript inside an HTML file using a script tag or in a separate JavaScript file.

3. What is jQuery? Is it still popular today?

jQuery is a JavaScript library that makes working with websites easier. It is still used, but it is less popular than before.

4. What is the most popular front-end JS library today?

React is one of the most popular front-end JavaScript libraries. It helps build interactive websites.

5. How does your code prevent the form from being submitted? Why do we need to prevent it?

The code uses event.preventDefault() to stop the normal form submission. This allows JavaScript to check the information without reloading the page.
