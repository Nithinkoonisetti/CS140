Questions and Answers

1. What does the action attribute do?

It tells the browser where to send the form information.

2. What does the method attribute do?

It tells the browser how to send the form information.

3. What is the difference between POST and GET?

GET shows information in the URL. POST sends information in the request body.

4. How do you set a pre-set value, and how is it different from a placeholder?

  • Text box: Use value. Placeholder shows a hint.
  • Textarea: Put text between the tags. Placeholder shows a hint.
  • Select box: Use selected on an option.
  • Checkbox: Use checked.
  • Radio button: Use checked.

5. List the HTML5 form input types. Which ones did you use?

They include email, date, color, number, range, search, tel, url, time, month, week, and datetime-local. I used email, date, and color.
