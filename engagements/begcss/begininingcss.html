CSS

1. Inline, Embedded, and External CSS

Inline CSS is written inside an HTML tag. Embedded CSS is written inside a style tag in the HTML page. External CSS is written in a separate CSS file and connected to the HTML page.

2. Why Use External CSS?

We should use external CSS because it keeps our HTML clean and makes the website easier to change. One CSS file can also be used for many HTML pages.

3. What Is a Selector?

A selector tells CSS which HTML element we want to style. For example, we can use a selector to change the color, size, or font of a heading.
