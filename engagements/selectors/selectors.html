CSS Selectors

1. List out the different ways to select an item.

We can select an item by using an element, class, ID, or attribute.

2. What is the difference between an ID and a Class?

An ID is used for one specific element. A class can be used for many elements.

3. What is the difference between a SPAN tag and a DIV tag?

A span is used for a small part of text or content. A div is used to group larger sections of content.

4. What is the difference between a DIV tag and a HEADER, MAIN, or FOOTER?

A div is a general container with no special meaning. Header, main, and footer are semantic tags that tell us what type of content is inside.

5. What are the different ways to select a color?

We can select a color by using a color name, HEX code, RGB, or HSL.
