What goes in the Header?

The header usually has the website name, logo, title, or introduction. It can also contain the navigation menu.

What goes in the Nav?

The nav contains links that help users move around a website. The nav can be inside the header, but it does not have to be.

What goes in Main?

The main section will heave the most important content of the webpage. It can include paragraphs, pictures, lists, and other things about the topic.

What is HTML Validation?

HTML validation checks your code for errors and it will check if it follows HTML rules.
