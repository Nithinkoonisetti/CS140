Questions and Answers

1. Why don't we use the border attribute?

We don't use the border attribute because CSS is better for styling. It keeps the design separate from the HTML.

2. What is the easiest way to color every other row a different color?

The easiest way is to use the :nth-child(even) selector in CSS. It colors every second row.

3. What does the value in the parentheses of your structural pseudo-class mean? Give one other value you could use and which rows it would select.

The value tells CSS which rows to select. For example, even selects the 2nd, 4th, and 6th rows. We can use odd to select the 1st, 3rd, and 5th rows.
