1. What kind of photos are good to encode using JPEG?

JPEG is good for photographs and pictures with many colors and details. It is commonly used for pictures of people, cars, places, and nature.

2. What kind of photos are good to encode using GIF?

GIF is good for simple images with fewer colors, small animations, and simple graphics.

3. What is unique about the PNG format?

PNG can have a transparent background and keeps good image quality. It is useful for logos, icons, and graphics.

4. How do you resize your photo to the size it should be displayed?

I can resize the photo using photo editing software before putting it on my website.

5. Why should you resize photos using photo editing software instead of resizing it using CSS?

Photo editing software changes the actual size of the image and can make the file smaller. CSS only changes how large the image looks on the webpage, so the browser may still have to load the larger file.
