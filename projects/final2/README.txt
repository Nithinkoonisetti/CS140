BASIC F1 WEBSITE - STUDENT PROJECT

1. Open index.html in your browser to see the site.
2. Open the folder in VS Code to edit HTML and style.css.
3. To test the PHP form, install PHP, open Terminal in this folder, run: php -S localhost:8000
4. Open http://localhost:8000/contact.html and submit the form.
5. Upload the entire folder contents to a PHP-enabled web server.
6. Check all links and video, and validate all pages at validator.w3.org and style.css at jigsaw.w3.org/css-validator/.

The images in images/ are original simple SVG drawings created for this project. The form validates and shows a confirmation but does not store or email responses.

Please personalize the writing and check the sources before submitting.
