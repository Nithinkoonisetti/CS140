EXPLORE HAWAII — 6-page student website

Open index.html to preview the static pages. To test the PHP form locally:
  cd explore-hawaii
  php -S localhost:8000
Then visit http://localhost:8000

Upload the entire folder contents to a PHP-enabled web host. Static-only hosts will not process process.php.

IMPORTANT BEFORE SUBMISSION:
- Images are remotely loaded from Unsplash CDN. Confirm every image works and accurately represents its caption. For full offline reliability, download properly licensed images to images/ and update src and attribution links.
- The YouTube embed is a placeholder video ID and must be verified/replaced with a working relevant video; update the timestamped source link too.
- Validate every HTML page at https://validator.w3.org/ and CSS at https://jigsaw.w3.org/css-validator/.
- Form processing validates and displays confirmation but intentionally does not store/email user information.
- References are inline on multiple pages, not on a separate references page.
